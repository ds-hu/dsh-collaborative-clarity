Install

dsh plugin --profile web add \
  link:D:/Projects/dsh-collaborative-clarity

Local link installs as-is. From GitHub, pnpm runs prepare — and refuses it the first time:

ERR_PNPM_GIT_DEP_PREPARE_NOT_ALLOWED
allowBuilds:
  @ds-hu/dsh-collaborative-clarity@https://
    codeload.github.com/ds-hu/…/tar.gz/<sha>: true

The key contains the commit SHA, so a new push needs a new approval.

What it buys

  • A compiler over both halves — including the 1,349-line client file, which can finally be split into modules.
  • One place that knows the bundle id: the build reads package.json.name into the loader wrapper instead of the literal being typed by hand inside client.js.
  • One shape across the fleet — personal-track, pocket and toolbridge all build this way, so pnpm test means the same thing everywhere.
And what it costs is on the other side of the decision: a devDependency, three tsconfig programs, and lib/ that must be rebuilt and committed with every source change — a stale lib/ installs cleanly and simply runs the old code.
