Collaborative Clarity

Decision rounds and real-test gates for DeepSeek Harness, in the right sidebar.

npmv0.3.2 licenseApache-2.0 DeepSeek Harnessplugin

What it does

  • Shows the decision. The agent writes the smallest file that makes a decision concrete — a screen, a type, a function — and opens it beside the chat.
  • Collects a precise answer. You annotate the element, the phrase, or the line you disagree with, pick a variant, and the tool returns your answer as structured data.
  • Refuses to call it tested. A change is built until a human has run the scenario and recorded what they saw.

Why a round, and not a question

A question typed into a transcript hides the thing it is about. Alternatives collapse into one paragraph, the reasoning arrives as persuasion, and what remains is a record of what everyone thought at the time. The artifact is the part that survives: you can point at a label, a line, or a whole screen and say this.

So the unit of collaboration is a round — one decision, one artifact set, one blocking wait, one record — and the agent states a recommendation and its foreclosure before you answer, not after.

The loop

  1. Inspect. The agent reads the code and the earlier decisions first.
  2. Open a round. One or two artifacts, a recommendation, at least one stated foreclosure.
  3. Wait. The tool call blocks; waiting costs no tokens.
  4. Annotate, decide. You comment on what should change, then accept, revise, reject, or leave it open.
  5. Build, then prove. The agent implements, prepares the build, and opens the test gate below.

Install

dsh plugin --profile web add @ds-hu/dsh-collaborative-clarity

Needs DeepSeek Harness with the web profile; from a checkout use link:D:/path/to/dsh-collaborative-clarity. No build step, one runtime dependency. Non-blocking rounds also need @deepseek-ai/dsh-tool-jobs. Version 0.x — the verified surfaces and the gaps are in 06-implementation.md.

What a round leaves behind

Round recordThe decision, the recommendation, the accepted foreclosures
AnnotationsWhat you pointed at, and whether it was resolved
Test recordWho ran the scenario, and what they saw

The artifact itself is disposable evidence; the tab is not a document store.
