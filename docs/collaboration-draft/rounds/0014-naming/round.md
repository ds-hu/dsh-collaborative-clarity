# Round 0014 — 面板说中文之后的第一轮抽查

**Decision:** 面板里那些指着位置的评论，叫「批注」还是「评论」？
**Variant A:** *批注* —— 「标注」是动作，「批注」是结果，两个词各管一段。
**Variant B:** *评论* —— 代码评审、issue 都在用，不用先解释两个词的关系。
**Recommendation:** A.
**Accepted:** A.
**Forecloses:** ① 「批注」在港台语境里常指老师给学生作业的评语，用在按钮旁边可能显得一本正经；
② 选了它就等于让「标注 / 批注」成对出现，而英文那边是 Annotate / Comments，中英不再字面对齐。

## Why this round

Round 0013 把面板接上了 `ctx.locale`，但没人真的看过它长什么样。这一轮的目的就是**看一眼**：
artifact 故意做得很小，注意力留给面板自己的按钮、列表和小标题。顺带问一个确实需要定的用词——
列表标题到底叫「批注」还是「评论」。

## Full review

一次真看，带回了后面这一串。它们都是同一次反馈，不是各自独立的决定：

| 位置 | 之前 | 之后 | 为什么 |
|---|---|---|---|
| 标题下的推荐行 | `推荐 ` + 值（只有一个空格） | `推荐：` + 值 | 中英混排时那一个空格会被吃掉 |
| 那行标签 | 放弃 | 代价 | 「放弃」像是在说 agent 放弃了什么 |
| 代价 | 两条用 `; ` 拼成一行 | 各自一行、带项目符号 | 两句话拼在一起读不断句 |
| 真实/模拟/省略 | `·` 连成一小段灰字 | 各自一行 | 同上，`·` 分隔符在这行是反效果 |
| 变体角标 | `recommended`（漏翻） | 推荐 | 0013 替换时漏掉的一个字面量 |
| 列表标题 | 评论 | 批注 | 本轮的决定 |
| 空列表提示 | 「点『标注』**指**一个元素」 | 「点一个元素、划一段文字，或者点一行代码，就可以在这里写」 | 「指」不是按钮会做的事 |
| 拒绝按钮 | `都不要 A&B` | `都不要` | 说了「都不要」就不用再点名 |
| 修改按钮 | `改 A` | `继续修改 A` | 「改」太短，像是破坏性动作 |
| 取消按钮 | `待会儿再说` | `取消这一轮` | **它真的会取消**，见下 |
| 测试关小标题 | 前提/步骤/预期/失败的迹象/怎么回滚 | 前期准备/测试步骤/预期结果/失败迹象/回滚方法 | 五个标题要同一套说法 |
| 命令行 | `运行 <code> 复制` | `命令：<code> 复制` | 「运行」读起来像按钮 |
| 受阻 | 受阻 | 无法测试 | 「受阻」像是产品状态，其实只是这次测不了 |
| 返回 | 返回 | 返回上一步 | 说清楚退到哪 |
| 触发按钮 | 我好了，开始测 | 准备完成，开始测试 | 上一句太口语 |

`都不要` 改成了带占位的字符串 `Reject {variants}` / `都不要`，所以英文仍然是 `Reject A&B`，中文不再
重复点名。

## 一个语义问题：「待会儿再说」

按下去之后，`submit('cancel')` → `POST /decide { verdict: 'cancel' }` → round 关闭，工具调用以
`cancelled` 返回。**它不是挂起，是取消。** 原来那个文案在承诺一件代码没做的事，所以改成
「取消这一轮」。

真要做「待会儿再说」，得让 round 进入 CONTEXT 里写过的 **Park** 状态（等一会儿还能回来答），
那是 store 和工具调用一起改，应该单独开一轮。
