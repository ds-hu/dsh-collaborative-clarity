要写的东西（A）

  • 状态多两个：editingIndex、editText。只一条在编辑，点另一条的「编辑」＝先存这条再开那条（还是拒绝？我按「先存」写，除非你要「先问」）。
  • 保存只换 text：comments[i] = { ...comments[i], text }，锚点、变体、artifactHash 一律不动，位置不动。
  • 空文字保存 → 用现有的「先写一条批注」拒绝，不静默删行。
  • Ctrl+Enter 保存、Esc 取消；行内其余地方点击仍然＝「在 artifact 里指给我看」（编辑框和按钮吃掉自己的点击）。
  • 仍是本地 state：批注本来就不落盘，编辑也不引入存储。
