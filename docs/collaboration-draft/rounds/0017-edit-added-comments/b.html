要写的东西（B）

  • 状态还是两个：editingIndex + 复用现有的 commentText（回填进去），「添加」按钮按 editingIndex 切文案。
  • 点「编辑」时必须先 setPendingAnchor(null)：输入框是锚点专用的，两个用途不能同时占。
  • 保存同样只换 text，锚点、变体、artifactHash 不动；空文字保存 → 现有「先写一条批注」拒绝。
  • 编辑中「所属变体」下拉要禁掉（变体不可改），否则保存会把批注搬到另一条变体上。
  • 未点 Add 的字仍然随决定送出——编辑中的字算不算？我按「算，存回去之后才随决定走」写。
