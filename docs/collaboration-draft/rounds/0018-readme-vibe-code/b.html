What goes wrong when you vibe code

Handing the build to an agent is fast, and three things go wrong in the same way each time. None of them is a badly worded prompt; each is a missing object.

  • You meet the interface late. The agent decides how a screen behaves, builds it, and you see it when it is finished. A round puts the screen in front of you before it is built.
  • The architecture becomes someone else's. A round carries the ten lines that matter, a recommendation, and what it forecloses.
  • Green tests stand in for a real test. A round ends at a gate a human has to run.
