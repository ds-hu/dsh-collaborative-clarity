# Round 0018 — README 首屏那个 `vibe code`

**Decision:** README 首屏那个 `vibe code`：留着，还是换成说人话的标题？
**Variant A:** *留着* —— 标题一字不动：`## What goes wrong when you vibe code`。
**Variant B:** *换掉* —— `## What goes wrong when you hand the build to an agent`，中文版跟着改。
**Recommendation:** A —— 它是最快的筛选器，认的人一眼知道自己来对了地方。
**Accepted:** A，没要求改一个字。
**Forecloses:** 不认这个词的人在第一屏被挡一下；两三年后这个词会显得旧，届时仍要再赌一次。

## Why this round

0011 重写 README 时就记下了这笔账：标题里这个流行词是**赌**——认的人立刻点头，不认的人在
第一行就出局。它一直挂在 TODO 上，等一次明确的「留」或「换」。这一轮就把它结清：
A 是什么都不做（这本身也是一个决定），B 是换成一句不用查词也能读懂的话。

中文版写的是「Vibe coding 会踩的坑」，所以两边必须一起动或一起留——这也是 B 的代价之一。

## Outcome

**没有代码改动。** 标题保留，README 与 `README.zh-CN.md` 都不动。本轮唯一产出是这个决定
被记下来，以及下一次重写时知道它是**选过的**、不是随便写的。

## Verification

- 这一轮同时是 [0017](../0017-edit-added-comments/round.md) 的真机测试：批注被写下来、用
  「编辑」改过、再随接受送出。

## 代价

- `vibe code` 会过气。到那天这一轮要重开，而不是当成从来没决定过。
