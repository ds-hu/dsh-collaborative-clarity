B — sessionStorage。草稿按 round id 写进本标签页的 storage。面板卸载、页面刷新都还在； 代价是批注正文落在磁盘上，并且要多一套「什么时候清」的规则。

什么时候还在 刷新也救得回来

动作批注还在吗
切到别的右侧栏 tab，再切回来还在
切到别的会话，再切回来还在
按 F5 / 刷新页面还在
宿主重启、插件重载后刷新还在，但轮次可能已经没了
换一个浏览器标签页 / 窗口各存各的

代价清单

批注正文落在磁盘上（可能含你贴的代码、内部路径）
要定清理规则：round id 已经不存在了，这条草稿留多久？
JSON 解析要防坏数据：storage 里的东西不是我们写的也能进来
同上限：一轮一条，要不要设条数上限
