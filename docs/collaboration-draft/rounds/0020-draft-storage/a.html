A — sessionStorage。draft 写进本标签页的 storage，键还是 round id。刷新、宿主重启后刷新、 切 tab 都在；**关掉这个标签页就没了**，它自己会过期，不用写清理规则。

活多久 标签页的寿命 = 草稿的寿命

动作批注还在吗
切到别的右侧栏 tab，再切回来还在
按 F5 / 刷新页面还在
宿主重启、插件重载后刷新还在（轮次可能已没了）
关掉这个标签页 / 窗口没了
另开一个窗口看同一个会话各存各的

代价清单

批注正文仍会落盘（浏览器把它写到磁盘，只是关页即删）
同一个标签页开很多轮，要跟页面内存一样设个条数上限
关页那个动作没救；但那通常是你已经决定、或者早就不看了的时候
