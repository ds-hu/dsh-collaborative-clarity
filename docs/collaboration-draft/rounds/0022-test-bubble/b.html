为什么不再加一条 一次工作一条气泡就够

  • 决定气泡记的是「在两条路之间选了哪条」；测试结论是这一步工作的状态，不是一次选择。

  • 工具行本来就是工具结论的天然所有者：它带着 prepared、命令、观察、截图，气泡只能抄一部分。
