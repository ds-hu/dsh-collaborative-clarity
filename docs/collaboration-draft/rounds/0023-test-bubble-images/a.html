为什么图先不进 一句话可以抄，一张图要通道

  • 观察是文字，照着事件的载荷就能画；截图现在是项目目录里的 PNG，工具结果里只有 { path, bytes }，对话行拿不到能加载的地址。
  • 给它一条地址有两条路：在 /clarity/api 上加一条会读文件的路由（那条路由在鉴权栅栏外， 谁连上端口谁就能取图），或者把截图改存成会话附件、让结果带附件引用——后者要动宿主半边。
  • 两件事都能做，但它们是「换掉截图的存储方式」，和「把观察补进气泡」不是同一步。
