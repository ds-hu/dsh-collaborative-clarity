# Round 0023 — 观察进气泡之后，截图也进去吗

**Decision:** 测试气泡里，观察写进去之后，截图也进去吗？
**Variant A′:** *观察进气，图留工具行* —— 气泡写「2 张截图 · 在工具行里看」；宿主零改动。
**Variant B′:** *观察和缩略图一起进* —— 截图改存会话附件，气泡与工具行都能长图；要改宿主。
**Recommendation:** A′ —— 先补全文字，图另开一轮。
**Verdict:** **revise**（甲 a 上带一条批注）。

## 批注

> 不要「在工具行中查看」，因为工具行也看不到。话说有没有办法做成点击后可以在右侧边栏显示的
> 超链接，然后气泡里显示图片路径？比如 AI 调用 read_image 的时候，工具行就会有显示这种东西。

这条批注抓到一个**假话**：A′ 写着「在工具行里看」，而工具行把结果当 JSON 文本渲染，
`{ path, bytes }` 没有预览。工具行能出图只有一条路——结果里带附件引用，`read_image` 就是这样，
ui-tool 的 `tool.call.images` 画廊接住它；我们的结果是文件路径，进不了那个画廊。

批注同时给出了方向：路径做成可点的超链接，在右侧边栏看图。

## 结果

没有实现。修订 → [round 0024](../0024-shot-paths/round.md)。
