为什么这样压 跟工具调用学它的默认态

  • 工具调用没展开时只有一行摘要，路径这种「需要时才看」的东西默认不该占两行。
  • 但路径又不能省：它是唯一能把图送到右侧栏的东西。所以折叠而不是删掉。
  • 展开在气泡内完成，不新开边栏 tab；路径本身才是打开边栏的那一下。

机制 一行 + 一个展开态

默认一行按钮：▸ 截图 {n} 张（en：Screenshots ({n})）
展开同一行换成 ▾，下面列出 n 条路径，每条 onClick = openFile(path)
状态渲染器里一个 useState，不进会话事件，也不进草稿
宿主零改动

文案 最终，两表同键

键en / zh
bubble.shotsScreenshots ({count}) / 截图 {count} 张
bubble.shotsShowShow the screenshot paths / 展开截图路径
bubble.shotsHideHide the screenshot paths / 收起截图路径
bubble.openShotOpen {name} in the sidebar / 在右侧栏打开 {name}
代价：多点一次才看得到路径；展开态不记忆，行重新挂载就回到折叠（聊天行本来也不记展开态，工具行同样）。 1 张时仍是这一行，写「截图 1 张」；0 张时整段不出现。
