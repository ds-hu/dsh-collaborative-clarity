# 这一版的面板，动了

Round 0028 定了动效的边界：**新的一轮升进来，其余的动都是对你动作的回答。** 下面是真正落进
`client.js` 的东西——你现在看到的面板，就是它。

## 到达

打开一轮，面板整块从下面 6px 升上来，每隔 40ms 一件，240ms 落定：头 → 标注条 → 卡片 A →
卡片 B → 批注区 → 操作条。每轮只播一次；重渲染不会再演一遍。

## 你的动作

| 你做了什么 | 面板怎么答 |
|---|---|
| 悬停卡片 | 描边加深，150ms |
| 点卡片 | 上浮 1px、一层软阴影、表头染成第二层灰，圆点从 55% 弹到 100% |
| 悬停按钮 | 一层内阴影铺过去，不改它自己的底色 |
| 按下按钮 | 缩到 99.6% |
| 加一条批注 | 只有新加的那一行升 4px；刷新读回来的草稿不会一行行自己出现 |
| 按「接受」 | 转圈 + 一道扫光；标签不换、宽度不变，所以这一排不会跳 |
| 键盘聚焦 | 1px 蓝描边；输入框换成一道 1px 蓝边 |

一套时长阶梯：**90 / 150 / 240ms**，一条曲线 `cubic-bezier(.2,0,0,1)`。

## 吸底

「接受 / 继续修改 / 都不要 / 取消这一轮」钉在面板底部。一条变体带多少推荐和代价，都不再影响你
够不够得着它。

## 界面整理（这一轮顺带做掉的）

- 批注属于哪条变体：下拉框改成 **A / B 两个小徽章**，一次点击，也不把你当前在哪一项藏起来。
- 批注区标题带上条数。
- 空列表不再画那句「还没有批注……」。邀请的话由标注条和下面的输入框自己说——那句话是每屏都在
  说一遍的成本。
- 「发送中」不再看起来像「不可用」：这颗按钮不吃禁用态的 0.45 透明度（它是内联写的，所以豁免
  也写在内联样式里）。测试动作条同理：你按下的那个动词才说自己在工作。

## 系统要求减弱动效

时长全部压到 1ms，升起、弹出、上浮、按下、扫光全关，转圈留下（它是进度，不是装饰）。第一帧就是
可见的，不会留一块看不见的面板。

## 验过什么、还差什么

真机过了：升起、吸底、选中、发送中都是你亲手看过的（`clarity-test-mwcy7vn3-1e77f7`，pass）。
合同测试 101 条全绿，样式表也单独喂给 Chromium 量过了——里面就查出两处真的坏了：发送中的豁免被
内联样式盖掉，卡片的焦点环被自己的 `outline: none` 掐掉。两处都已修，改完又反向验过。

还差两条：两块 iframe 在到达动效里完成首帧会不会在慢机器上闪（没量过），以及开着系统
「减弱动态效果」看一遍面板（样式表侧量过，人没看过）。
