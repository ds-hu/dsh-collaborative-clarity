# Round 0028 — 动效的边界

**Status:** tested
**Tool round:** `clarity-mwccv0ad-170d4d`
**Opened / decided:** 2026-11-12
**Artifacts:** [a-quiet.html](a-quiet.html), [b-alive.html](b-alive.html)

用户的原话是「准备优化动效，界面 UI 显示」，没给方向。这一轮只决定一件事：**动效的边界**——
其余的界面整理（吸底操作条、悬停与焦点、选中态、空掉的批注区、A/B 小徽章替换下拉框）两版
完全一样，写在一份 mock 里，谁被选中就跟着谁一起实现。

## 决定

面板的动效收到什么程度：只在你动手时动，还是新的一轮到达时也动？

## 两个变体

| Id | 标签 | Artifact | 真实 | 模拟 | 省略 |
|---|---|---|---|---|---|
| A | 收：只在你动手时动 | [a-quiet.html](a-quiet.html) | 卡片、批注区、操作条的尺寸与文案；90/150/240ms 与一条曲线；悬停、选中、按下、发送中、键焦 | artifact 视口 150px（真实 300px）；空状态画面与批注内容；脚本自动点的那几下 | 发出之后那一屏；`clarity_test` 闸门的界面 |
| B | 起：到达也动 | [b-alive.html](b-alive.html) | A 的全部 + 到达编排（每 40ms 一档、共 240ms、上升 6px）+ 四处分位移 | 同上 | 同上 |

推荐是 A：每一下动画都由用户自己触发，面板在阅读时是静止的；代价是新的一轮换进来时面板不动，
只能靠会话行那个点和 agent 的话发现它。

## 结果

```json
{"status":"decided","roundId":"clarity-mwccv0ad-170d4d","verdict":"accept","selected":"b"}
```

**接受了 B，拒绝了推荐。** 理由不必猜：B 的卡片里写着自己那句话——新的一轮升进来，等于替用户把
「换内容了」说了一遍。代价也一并接受：

- 每一轮都有一段动，读的时候面板不是静止的；
- 两块 300px 的 iframe 在动效里完成首帧，慢机器上可能闪一下；
- 多约 60 行动画代码，还要一个「每轮只播一次」的 key。

实现完又开了一轮验收（[SUMMARY.md](SUMMARY.md)，`clarity-mwcy6xp7-4e7d8d`）：它把这一遍的账单
摆出来，顺带让面板有内容可看、能真的动一次。那一轮被接受（`accept a`）。

## 建了什么

动效没有内联在 `style` 里——`:hover`、`:focus-visible`、`@keyframes`、`::after` 都写不进内联
样式对象。所以 `client.js` 里多了一份只注入一次的样式表（`STYLE_ID = 'clarity-motion'`），
挂在面板的滚动根上（`.clarity-scope`）。这份样式表对整页有效，所以**每个选择器都带 `clarity-`
前缀，除 `.clarity-scope` 自己外每条规则都收在它下面，每个 `@keyframes` 也带前缀**——别人的
`.row` 或 `rise` 不该被它碰到。

- **一份时长阶梯**：`--clarity-d1: 90ms`（按下、悬停）、`--clarity-d2: 150ms`（描边、底色、
  透明度）、`--clarity-d3: 240ms`（到达、插入、弹出），一条曲线 `cubic-bezier(.2,0,0,1)`。
- **到达编排**：滚动根带 `key={round.id}` 和 `clarity-arrival` 两个东西——换轮就换根，所以每轮正好播
  一次，重渲染不会重播。子元素依次升起（`nth-child` 每档 40ms，240ms 落定，6px）。
- **被用户触发的动效**：悬停用一层内阴影 washes（`inset 0 0 0 999px`）而不改底色，理由是它落在
  任何填充上，且不用和任何内联样式抢优先级；焦点环 1px `--dsw-focus-ring-color`；按下缩到
  99.6%；选中卡片上浮 1px + 一层软阴影，表头染成 layer-2，圆点从 55% 弹到 100%。
- **发送中**：**你按下哪一个动词，哪一个说自己正在工作**——一道 1.2 秒的扫光、一个 9px 的
  转圈、`cursor: progress`，其余三个只是变灰。主按钮不换文案（「接受 A」还在，说的是要发什么），
  它的转圈**在静止时就有那个 9px 的盒子**、只是不显形，所以宽度不会在按下的那一帧变、这一排也
  就不会重排。它同时还是 `disabled` 的，而那份 0.45 透明度是**内联**的，所以「不吃禁用态」这件事
  也写在内联样式里（全不透明 + 进度光标）——样式表够不到内联声明。
- **新加的批注**：只有这一轮里刚加的那一行升 4px（`data-new`，索引记在 `lastAdded`），
  刷新后读回来的草稿不会一行一行地自己出现。
- **吸底操作条**：`position: sticky; bottom: 0`，因此滚动根的底部内边距从 18px 收成 0，由这条自己
  带来——不然条会浮在底部 18px 之上，让内容从缝里露出来。
- **界面整理的其余各项**：批注变体从下拉框改成 A/B 小徽章（一次点击，且不会把你当前在哪一项藏
  起来）；批注区标题带上条数；空列表不再画那句「还没有批注……」，邀请的话由标注条和下面的输入框
  自己说（`comments.empty` 两个表里一并删掉）。
- **`prefers-reduced-motion: reduce`**：三档时长压到 1ms，到达编排、弹出、上浮、按下、扫光全关，
  转圈留下——它是进度指示，不是装饰；`scrollIntoView` 也改成 `auto`。

`BRAND` 仍然用于圆点与「推荐」标签；选中卡片的描边、内描边、上浮和表头底色从内联样式搬进了
样式表，因为内联样式会赢过类规则。同理，卡片上那条内联 `outline: none` 被删掉了——它会连同
浏览器自己的焦点环一起掐掉，键盘用户就看不见哪张卡被聚焦。`data-tone="primary"` 只标在实心主
按钮上（接受、保存编辑、开始观察、通过），悬停样式才知道该改哪颗。

## 代价

- 每次换轮都有一段 240ms 的动；A 那条「读的时候面板是静止的」被明确放弃了。
- 面板多了一份全局样式（一个 `<style id="clarity-motion">`）。它随 `apply` 注册、随 dispose 移除，
  但它是这个插件往页面上放的第一件全局东西。
- `comments.empty` 的文案没了：空列表现在什么都不说，靠标注条那句提示和输入框的占位符。
